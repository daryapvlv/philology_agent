# Интерфейс Reflex

Запуск из корня проекта (Python 3.11–3.13):

```sh
source .venv/bin/activate
python -m pip install -r requirements.txt
reflex run
```

Neo4j и LLM настраиваются переменными окружения (см. `.env.example` в корне);
`.env` не загружается автоматически, значения нужно экспортировать вручную.
Без Neo4j работает только общий чат без книги; без ключа модели — просмотр и
ручные правки структуры.

Книга хранится и редактируется в Neo4j; локально — только оригиналы файлов,
кэш LLM и переписка.

Вкладки:

- **Диалог** — один агент с инструментами: ищет фрагменты, расширяет и уточняет
  выборку, меняет статусы, читает текст вокруг найденного.
- **Разметка** — границы произведений/глав/сцен, ручные правки и подтверждение
  структуры (сцены подтверждения не требуют).
- **Подготовка** — построение сцен, чанков, embeddings и графа сущностей для
  главы или всей книги; без него поиск по персонажам/месту действия недоступен.
- **Находки** — evidence table текущего диалога: статус, причина решения,
  «как искала», экспорт в CSV/Markdown/JSON.

Подробнее о сценарии работы, каналах поиска и ограничениях — в
[корневом README](../README.md) и [retrieval/README.md](../retrieval/README.md).
