# AI-ассистент для интерактивного поиска в гуманитарных текстах

Приложение для работы с книгой: структура произведений и глав, сцены, ручные правки
и поиск релевантных фрагментов. Рабочая книга хранится в Neo4j. LangGraph-агент
сам выбирает инструменты поиска и работы со структурой; весь текст книги
в контекст модели не отправляется целиком.

## Запуск

Требуются Python 3.11–3.13 и запущенный Neo4j 5.26+.

```sh
python3 -m venv .venv  # только если окружение ещё не создано
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните переменные (Neo4j, ключ модели,
опционально — отдельные модели по стадиям пайплайна и embeddings). Файл не
загружается автоматически:

```sh
set -a && source .env && set +a
python -m structure.cli.graph check
python -m infrastructure.neo4j.migrate
reflex run
```

Откройте адрес из вывода Reflex (обычно http://localhost:3000). Без модели
доступны просмотр и ручные правки структуры; без Neo4j — только общий чат.

## Как пользоваться

1. Прикрепите книгу через «+ Книга» и подтвердите границы во вкладке «Структура».
2. Во вкладке «Граф» запустите «Pipeline данных» для главы или всей книги —
   это построит сцены, чанки, сущности и (опционально) embeddings.
3. В чате опишите, что ищете, — агент составит план, найдёт кандидатов, проверит
   их по критерию и покажет точные цитаты с координатами. «Найди ещё» продолжает
   поиск с сохранённой позиции.
4. Правки структуры и сущностей делаются через чат или вкладку «Разметка»;
   найденные фрагменты — во вкладке «Находки» (evidence table).

Полнота обеспечивается на стадии поиска, точность — на стадии проверки по
критерию: наличие точной цитаты не гарантирует правильную интерпретацию.
Смысловой (embedding) поиск включается чекбоксом в «Подготовке» и работает
только при настроенной embedding-модели — без неё явно сообщается об ошибке,
а не подменяется поиском по словам.
