# Ingest книги

`ingest` владеет полным первичным конвейером книги:

1. сохраняет исходный EPUB/Markdown;
2. извлекает текстовые элементы и оглавление EPUB (или заголовки Markdown);
3. строит начальное дерево секций;
4. собирает итоговый снимок;
5. сохраняет неизменяемый `elements.json` в `artifacts/books/<book_id>/`;
6. одной транзакцией импортирует канонический текст и секции в Neo4j.

`elements.json` — воспроизводимый артефакт разбора, а не узлы доменного
графа. Обычное чтение и retrieval используют `LiteraryBook.text` и символьные
границы секций. Артефакт загружается только для анализа и ручных операций,
которые пока адресуют исходные элементы по номерам.

Первичная загрузка не вызывает LLM: структура EPUB берётся из его оглавления, а при его отсутствии из заголовков текста. Поисковые чанки и эмбеддинги в этот конвейер
не входят: ими независимо владеет [`retrieval`](../retrieval/indexing.md).

```sh
.venv/bin/python -m ingest book.epub
```

Повторная загрузка того же файла идемпотентна и не перезаписывает сделанные позднее
ручные правки. Переходный импорт старых `structure.json` доступен через
`ingest.migration.import_saved_book`.
